# Ave 混剪工具 · 使用说明

> 给运营用的操作手册。从双击 exe 开始，一步步到导出成品。
> 出问题先看最后一节「常见问题」。
>
> ⚠️ **当前 `dist\Ave\Ave.exe` 是旧版打包**，没有「模型自动降级」那部分改动
> （实查 `/api/copy/list` 不返回 `vision_models`）。功能能用，但要拿到最新改动
> 需要重新执行 `打包.bat`。本文按最新代码写。

---

## 一、启动

双击 `Ave.exe`（在 `dist\Ave\` 文件夹里）。

会先弹一个黑色命令行窗口，然后自动打开浏览器界面。**那个黑窗口不要关**——
关掉就等于停止服务，界面会失灵。用完想退出就关它。

界面地址是 `http://127.0.0.1:8756/`。浏览器没自动打开就手动输这个地址。

### 首次运行会下载 1.5G 模型

第一次启动会下语音识别模型（约 1.5G），黑窗口里显示进度。
**这一步只做一次**，之后更新软件也不会重下。保持网络畅通，等它走完。

模型存在 `%LOCALAPPDATA%\Ave\models\`，不在软件目录里——所以换新版本 exe
不用重下。

### 端口被占用会自动处理

如果提示「端口 8756 被占用，已清理进程 xxxxx」，那是正常的，它自己解决了。

⚠️ **别同时开两个** Ave（比如源码版和 exe 版），后开的会把先开的杀掉。

## 二、界面从上到下

顶部有一行状态：**环境就绪** + **BGM 7 首（内置 0 · 自定义 7）**。
显示「环境就绪」才能正常干活。

### 1. 素材

填分镜素材的**根目录**，例如 `D:\Download\分镜`。可以点「选择文件夹」用弹窗挑。

填好点「**扫描**」，下面出现四个数字：

| 数字 | 含义 |
|---|---|
| 钩子 | 13 |
| 卖点 | 33（34 个文件——同名不同变体会归成一组） |
| 结尾促单 | 7（8 个文件） |
| 预计产出 | 39 条 = 钩子数 × 每个钩子用几次 |

**素材文件名必须按规范命名**，否则归不了组：

```
钩子-内容概括-1.mp4
卖点1-内容概括-1.mp4
结尾促单-内容概括-1.mp4
```

「内容概括」缺了的话，每个文件会各自算一组（不影响出片，只是不去重）。

### 2. 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 每条用几个卖点 | 5 | 一条视频里放几个卖点片段 |
| 每个钩子用几次 | 3 | **决定产量**：13 个钩子 × 3 = 39 条 |
| 画面倍速 | 1.2 | 这是**导出时**的整体加速，1.0 = 不处理 |
| 背景音乐音量 | 3% | 越小越不抢口播。0 = 完全不加 BGM |
| 字幕字号 | 12 | 需求要求 10–15 |
| 随机种子 | 空 | 填数字可复现同一批组合；留空每次重新随机 |
| 只跑前几条 | 0 | 先试跑用，填 2 就只出 2 条。0 = 全出 |

下面「本次将产出 **39 条**」会跟着参数实时变。

**两个开关**（默认都开着，建议别关）：

- **卖点自动分类去重**——同一条里不放两个讲同一件事的卖点。
  下面会显示聚类结果，例如「33 个卖点组 → 9 个主题」。关掉就纯随机、接受重复。
- **AI 补口播文案**——本身没口播的分镜，让 AI 看画面写一段口播再配音加字幕。
  关掉这些片段就只有画面、没声没字幕。

### 3. 无口播分镜的 AI 文案

显示当前用的视觉模型，例如 `视觉模型：doubao-seed-2-0-lite-260428`。

三个按钮：

- **测试视觉接口**——真发一次请求，确认模型能用。**改完凭证先点这个**。
- **识别并生成全部文案**——批量给没口播的片段写文案，有进度条、可中途停止。
- **查看**——列出所有片段和它们的文案，**可以手工修改**。

⚠️ **手工改过的文案不会被 AI 覆盖**。以后重新生成也不动它。
要让 AI 重写，得先在界面上把那条清空。

### 4. 背景音乐

「查看」看列表，「添加音乐」用弹窗选文件（支持 mp3 / wav / m4a / aac / flac）。

自己加的曲子存在 `%LOCALAPPDATA%\Ave\bgm\`，随软件自带的那些删不掉
（有授权限制，界面会拒绝并说明原因）。

### 5. 组合预览

先给你看几条会怎么组，点「重新抽样」换一批，「展开全部 39 条」看全部。

⚠️ **预览的序号跟成品对不上**。不填随机种子的话每次预览都重新随机，
想知道某条成品的真实构成，去「成品」区看那一条自己的记录。

### 6. 渲染

输出目录默认桌面的 `VEDIO抖音`，留空也是它。目录不存在会自动建。

点「**开始渲染**」。有进度条，可以中途停。
**39 条大约要 45~50 分钟**（2026-08-17 实测全量 2869 秒；本次 2 条 84 秒）。
先用「只跑前几条」填 2 试跑一下更保险。

### 7. 成品

顶上显示「39 条 · 1053MB」，点「刷新」更新。

每条都能直接点开预览播放。勾选「预览时按 1.2x 播放」就按倍速看。

**按 1.2x 导出全部**——导出到子目录 `导出_1.2x\`，**不覆盖原片**。
改倍速不用重新渲染（重渲 9 分钟，变速一条 1.4 秒）。

## 三、典型流程

1. 双击 `Ave.exe`，等浏览器打开
2. 填素材目录 → 点「扫描」→ 确认四个数字对得上
3.（第一次用这批素材）点「识别并生成全部文案」，完了点「查看」抽查几条，
   不满意的手工改掉
4.「只跑前几条」填 2 → 点「开始渲染」→ 在「成品」里看这 2 条效果
5. 满意了把「只跑前几条」改回 0 → 再点「开始渲染」出全部
6. 需要倍速版就点「按 1.2x 导出全部」
7. 点「打开输出目录」拿片子

## 四、常见问题

### 提示「配音失败」/「视觉接口失败」，一堆英文

**先去火山引擎控制台查账户余额。**

欠费会让配音和 AI 文案一起挂，而且报的错**字面上看不出是欠费**——
比如配音会说 `requested resource not granted`（像是"没授权"），
实际是欠费导致服务被停。2026-08-28 就踩过这个坑，结清后原样就好了。

余额正常再看别的：错误信息里会带火山引擎返回的原文，照着查。

### 渲染完 0 条成功

看失败原因那几行。最常见是配音服务不通（见上一条）。
**不是代码问题的话，界面会把服务端原话显示出来。**

### 提示「配音比画面长 12%，已加速压缩」

这是正常提示，不是错误。配音比画面长时会压一点画面速度去对齐，
已经处理好了，片子是完整的。

### 界面打不开 / 点按钮没反应

看那个黑窗口还在不在。关了就重新双击 `Ave.exe`。

### 想彻底停掉

关掉那个黑窗口就行。

### 换了凭证

凭证在 `%LOCALAPPDATA%\Ave\credentials.json`。
**改完要重启**（关掉黑窗口重新双击 exe）——软件是启动时读一次的。

改完先点「测试视觉接口」确认能用，再开始渲染。

## 五、文件都在哪

| 东西 | 位置 |
|---|---|
| 成品视频 | 桌面 `VEDIO抖音\`（可改） |
| 倍速导出 | 成品目录下的 `导出_1.2x\` |
| 语音模型（1.5G） | `%LOCALAPPDATA%\Ave\models\` |
| 自己加的 BGM | `%LOCALAPPDATA%\Ave\bgm\` |
| 凭证 | `%LOCALAPPDATA%\Ave\credentials.json` |
| 识别缓存 | `%LOCALAPPDATA%\Ave\cache\` |

放在 `%LOCALAPPDATA%\Ave\` 而不是软件目录，是为了**换新版 exe 不冲掉**
模型、缓存和你加的音乐。
