### 换模型怎么换

改 `%LOCALAPPDATA%\Ave\credentials.json`，**改完重启服务**
（`config.py` 是 import 时读一次的）：

```json
{
  "ARK_API_KEY": "你的 Key",
  "ARK_VISION_MODELS": "doubao-seed-2-0-lite-260428,doubao-seed-2-1-turbo-260628,doubao-seed-2-1-pro-260628"
}
```

`ARK_VISION_MODELS` 那行可省，省则用代码里的默认降级链（就是上面这三个）。
Endpoint 不用填。老写法 `ARK_VISION_MODEL`（单数、单个模型）仍然认，
填了就只用那一个、不降级。

## 🟡 6. 分镜命名规范（影响解析准确度）

**为什么要**：工具靠文件名判断角色和内容，命名不规范会解析错。

**约定格式**（用户 2026-08-14 确认）：

```
钩子-内容概括-N
卖点M-内容概括-N
结尾促单-内容概括-N
```

- `M` = 卖点顺序（脚本里第几个展示的内容）
- `N` = 变体编号（同一内容生成了多个时用来区分）
- `内容概括` = 这个分镜讲什么卖点（沥水、收纳、颜值……）

**现存素材里不合规的**，我已加容错但建议以后统一：

| 文件 | 问题 |
|---|---|
| `1/钩子-1.mp4`、`1/钩子-2.mp4` | 缺内容概括，无法判断是「同一钩子的两个变体」还是「两个不同钩子」 |
| `6/卖点-滴水承接-1.mp4` 等 3 个 | 卖点缺 M 序号 |
| `3/卖点0-...` | 卖点从 0 开始编号（其他文件夹从 1 开始）|

**钩子归组已确认**（2026-08-14）：`1/钩子-1.mp4` 与 `1/钩子-2.mp4` 是
两个不同的钩子。代码已按「内容概括缺失时不归组」处理，产出 **39 条**。

但仍建议以后补齐内容概括 —— 靠文件名无法区分「变体」和「不同素材」时，
只能猜，猜错就会少产出视频或让相似片段进同一条。
