## 🔴 1. 火山引擎语音合成凭证（配音「小姐姐」）

**为什么要**：需求 4 要求所有分镜配音统一为「小姐姐」。这是字节的 TTS 音色，
剪映和火山引擎同源，官方渠道就是火山引擎。本地开源模型复现不了这个特定音色。

**怎么拿**：

1. 登录火山引擎控制台 https://console.volcengine.com/speech
2. 开通「语音技术 → 语音合成」（大模型语音合成 / 语音合成 TTS）
3. 在「应用管理」里创建应用，拿到三个值
4. 在音色列表里找女声音色，**记下音色 ID**（形如 `zh_female_xxx_moon_bigtts`）

**交付给我**：

| 项 | 说明 | 示例格式 |
|---|---|---|
| APP ID | 应用 ID | `1234567890` |
| Access Token | 访问令牌 | 一串字符 |
| Cluster | 集群名 | `volcano_tts` |
| 音色 ID | **关键**，决定听起来是谁 | `zh_female_shuangkuaisisi_moon_bigtts` |

**关于「小姐姐」这个名字**：火山引擎公开音色表里**没有**叫「小姐姐」的条目——
那是剪映 App 内部的显示名。请在控制台试听女声音色，挑一个你认为最接近
剪映「小姐姐」的，把 ID 给我。建议试听这几类：`爽快思思`、`temo`、
`灿灿`、`软萌兔兔`、少女音系列。

**费用**：按字数计费，量级约 1-2 元/万字。39 条视频每条约 100 字 ≈ 4000 字，
**一轮跑完不到 1 块钱**。可以放心测。

**注**：`D:\code\SKILL视频测试\SKILL.md` 里有一个火山引擎 Ark 的 API key
（那是文生视频 Seedance 用的），**语音合成是另一个产品，要单独开通**，

## 🟡 5. 分镜命名规范（影响解析准确度）

**为什么要**：工具靠文件名判断角色和内容，命名不规范会解析错。

**约定格式**（用户 2026-08-14 确认）：

```
钩子-内容概括-N
卖点M-内容概括-N
结尾促单-内容概括-N
```

- `M` = 卖点顺序（脚本里第几个展示的内容）
- `N` = 变体编号（同一内容生成了多个时用来区分）
- `内容概括` = 这个分镜讲什么卖点（沥水、收纳、颜值……）

**现存素材里不合规的**，我已加容错但建议以后统一：

| 文件 | 问题 |
|---|---|
| `1/钩子-1.mp4`、`1/钩子-2.mp4` | 缺内容概括，无法判断是「同一钩子的两个变体」还是「两个不同钩子」 |
| `6/卖点-滴水承接-1.mp4` 等 3 个 | 卖点缺 M 序号 |
| `3/卖点0-...` | 卖点从 0 开始编号（其他文件夹从 1 开始）|

**钩子归组已确认**（2026-08-14）：`1/钩子-1.mp4` 与 `1/钩子-2.mp4` 是
两个不同的钩子。代码已按「内容概括缺失时不归组」处理，产出 **39 条**。

但仍建议以后补齐内容概括 —— 靠文件名无法区分「变体」和「不同素材」时，
只能猜，猜错就会少产出视频或让相似片段进同一条。
