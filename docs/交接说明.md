# Ave 项目交接说明

> 给接手这个项目的同事。照这份文档能从零把环境跑起来。
> 有问题先看 `CLAUDE.md`（架构铁律）和 `docs/进度与待办.md`（当前状态）。

---

## 一、先拿到四样东西

源码在 GitHub，另外三样**不在版本库里**，要单独拿。

```bash
git clone https://github.com/YK-PrDi/Ave.git
cd Ave
```

| 要什么 | 大小 | 怎么拿 |
|---|---|---|
| 源码 | 1.7M | 上面那条 clone |
| ffmpeg + 字体 | 158M | `python 准备素材.py`（自动下载） |
| 语音模型 | 1.9G | **首次运行自动下**，不用手动 |
| **凭证 `credentials.json`** | 1K | **向交接人索取**，见下方第三节 |
| **BGM 音频** | 18M | **向交接人索取**（有版权，不进版本库） |

### 为什么这些不进 git

不是漏了，是刻意的（`.gitignore` 里都写了原因）：

- **ffmpeg 138M**：二进制每改一次 git 存一份全量，仓库很快膨胀到 GB 级；
  且它是 GPL 构建、字体有非商用条款，进版本库等于版本库本身在分发它们
- **模型 1.9G**：更新应用不该冲掉它，所以放用户数据目录
- **BGM**：运营提供的曲子，有版权
- **凭证**：**仓库是公开的**，且 API Key 带计费。一旦提交等于把钱包挂网上，
  而且 git 历史删不干净、要重写历史

## 二、环境搭建

### 1. 装 Python 依赖

需要 **Python 3.11**（3.10 以下不行，`pillow==12.3.0` 要求 >=3.10）。

```bash
python -m pip install -r requirements.txt
```

国内网络慢就加镜像：

```bash
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2. 补齐二进制素材

```bash
python 准备素材.py          # 下载 ffmpeg + 字体
python 准备素材.py --check  # 只检查不下载
```

跑完应该看到：

```
  ✓ ffmpeg.exe  138M
  ✓ 思源黑体  16M
  素材齐全，可以打包。
```

### 3. 装前端依赖

需要 **Node.js**（建议 20+）。

```bash
cd frontend
npm install
```

## 三、放凭证（关键一步）

向交接人索取 `credentials.json`，放到：

```
%LOCALAPPDATA%\Ave\credentials.json
```

即 `C:\Users\<你的用户名>\AppData\Local\Ave\credentials.json`（目录不存在就新建）。

内容长这样（**值向交接人要，别自己编**）：

```json
{
  "ARK_API_KEY": "...",
  "VOLCANO_APPID": "...",
  "VOLCANO_TOKEN": "...",
  "VOLCANO_VOICE": "zh_female_xiaohe_uranus_bigtts",
  "VOLCANO_CLUSTER": "volcano_tts"
}
```

### 三条规矩

1. **绝不提交这个文件。** `.gitignore` 有三条规则拦它，但别依赖那个 —— 别往仓库里放。
2. **别贴进聊天群、issue、PR、日志。** 要传就私聊或用密码管理器。
3. **这套凭证带计费**（方舟按 token、TTS 按字数）。跑全量 39 条约 0.075 元，
   不贵，但别写死循环。

放好后验证：

```bash
python -c "from ave import config; print('TTS:', config.TTS_BACKEND); print('视觉:', config.VISION_BACKEND)"
```

应该输出 `TTS: volcano` / `视觉: ark`。如果是 `stub`，说明凭证没读到 —— 检查路径和文件名。

## 四、验证跑通

按这个顺序，每步都要过。

### 1. 后端出片（最关键）

```bash
python -m ave.pipeline --limit 2 --seed 7
```

**必须真出片**。预期约 84 秒、两条 27MB 左右的 mp4 落到桌面 `VEDIO抖音`。

失败看报错：
- `TTS 返回 403` → 凭证问题或**账户欠费**（见下方「已知坑」）
- `方舟视觉接口 403` → 同上

### 2. 前端类型检查

```bash
cd frontend
npx vue-tsc -b --noEmit
```

必须无输出（退出码 0）。

### 3. 起服务看界面

```bash
python -m ave.launcher
```

会自动开浏览器到 `http://127.0.0.1:8756/`。顶部应显示「环境就绪」。

### 4. 打包（可选）

```
打包.bat
```

6 步，产出 `Ave-分发.zip`。⚠️ **这个 zip 里有明文凭证**，只发内部同事。

## 五、必读的三份文档

| 文档 | 什么时候看 |
|---|---|
| `CLAUDE.md` | **动手前先看**。18 条架构铁律，都是踩过坑总结的，违反会改爆 |

| `docs/ARCHITECTURE.md` | 碰架构决策或遇到怪问题时查 |

另外两份是给运营的：`docs/使用说明.md`（操作手册）、`docs/资源需求清单.md`（凭证开通步骤）。

### 铁律里最容易踩的几条

1. **批处理必须存 GBK**，存 UTF-8 会中文乱码 + `if`/`goto` 流程断裂
2. **CLI 入口必须 reconfigure stdout 为 UTF-8**，否则 print emoji 直接崩
3. **`except HTTPError` 必须排在 `except URLError` 前面** —— 前者是后者子类，
   写反了 4xx 会被当网络抖动白重试
4. **配音固定语速、画面逐段适配**，不准反过来
5. **成品构成只认 `.ave-manifest.json`**，不准按序号对预览结果

## 六、已知坑（省你踩一遍）

### 账户欠费会让两条链路一起挂，但报错看不出

火山账户欠费时：
- 方舟报 `AccountOverdueError`（这个还算明确）
- TTS 报 `code 3001 ... requested resource not granted`
  ——**字面像「音色没授权」，实际是欠费**

判据：**曾经跑通过就说明授权存在，遇到 `not granted` 先查余额。**
2026-08-28 结清后同一套凭证原样就通了。

### 界面报「未配置方舟 API Key」不一定是真的

已修（`5bb9b9c`），但原理值得知道：这类全局状态只能从 `/api/health` 拿，
不能从要扫素材目录的接口拿 —— 目录不存在会 400，前端拿不到就停在初始值 `'stub'`，
于是谎报凭证没配。

### 批处理里的路径要按字节确认

`打包.bat` 曾把 `licenses\ffmpeg` 写成单个 `0x0C` 换页符（`\f` 被当转义吃掉），
GPL 许可检查恒失败、打包卡在第 0 步，而目录明明是好的。
屏幕上看着完全正常，只能按字节查：`open(f,'rb').read().count(bytes([12]))`。

同类风险：`\f` `\t` `\n` `\r` `\b` 开头的路径段（`licenses\fonts`、`web\temp`）。

## 八、GPL 合规（对外分发前必读）

随包 ffmpeg 是 **GPLv3 构建**，PyAV 自带 x264/x265（GPLv2）DLL。

- `licenses/` 目录**必须随包**，`打包.bat` 已自动处理
- 对外分发前要补齐 `licenses/ffmpeg/SOURCE-OFFER.md` 里的 `<待填>`（源码归档地址）
- `dist-src/` 里两个 tar.gz 的 SHA256 已钉进 SOURCE-OFFER，**别删** ——
  GPL 承诺三年有效期内要能重传，重新下载打包哈希会变

仅内部使用不涉及分发义务，但**一旦给外部就要合规**。
