# 新青年体 —— 授权风险说明

⚠️ **这个字体的免费授权仅限非商用。抖音带货是商业用途。**

## 实测证据

`fonts/新青年体.ttf` 用 Pillow 加载，读出的字族名带后缀：

```
WenYue XinQingNianTi (Non-Commercial Use)
```

非商用限制**写在字体文件自己的名称表里**，不是道听途说。

来源：从剪映字体目录拷出
`%LOCALAPPDATA%\JianyingPro\User Data\Resources\Font\新青年体.ttf`
（1.3MB，SHA256 `3965eb207306bf96593d1cf75178d637c68483bfc0656e46b99fba1d4d0d1287`）。
剪映内置它，不代表授权可以带出剪映用在自己的工具里。

## 当前处置

**默认已不使用它。** `ave/config.py` 的 `SUBTITLE_FONT` 默认值是
`"思源黑体"`（SIL OFL，可商用，见同目录 `SIL-OFL-1.1.txt`）。

但**文件仍随分发包一起带**（用户 2026-08-16 决定：两个字体都保留，
靠 `config.SUBTITLE_FONT` 开关切换）。

## 残留风险，不隐瞒

即便默认不用，**随包分发这个文件本身**仍在非商用授权的射程内 ——
分发即是一种使用。切换开关到 `"新青年体"` 后产出的带货视频，
风险更直接。

**这条风险由运营承担并已知悉。**

要彻底规避，两步：

1. 删掉 `fonts/新青年体.ttf`
2. `Ave.spec` 的 `datas` 里 `("fonts", "fonts")` 会自动少打这一个文件，
   不用改 spec；`config.FONT_FILES` 里那一项留着无害（`find_font()`
   找不到文件会回落，`/api/health` 会报字体缺失而不是崩）

## 视觉接近的免费商用替代

都完全免费商用、无需署名：

- **阿里巴巴普惠体 3.0** Black / Heavy —— 最推荐，字重够、覆盖字符全
- **得意黑 Smiley Sans** —— 窄体带斜度，短视频标题感强
- **抖音美好体** —— 字节自家开源字体，OFL 授权

换字体的做法：文件放 `fonts/`，在 `config.FONT_FILES` 加一项，
把 `SUBTITLE_FONT` 指过去。`subtitle.py` 不用改。
**换完必须实渲一次验证** —— Pillow 加载不了的字体等于没有
（`SOURCE-OFFER.md` 之外的另一个坑：曾下到一份 1.44MB 的假 OTF，
magic 是 `OTTO` 看着像真的，Pillow 报 `hmtx table missing`）。
