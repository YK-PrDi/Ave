# 阿里巴巴普惠体 3.0 —— 默认字幕字体

**授权：免费商用，无需授权、无需付费、无需署名。**

阿里巴巴官方公告的授权范围包含商业用途，个人和企业都可以免费使用。
带货短视频属于其许可范围。这是当前 `config.SUBTITLE_FONT` 的默认值。

## 用哪个字重

| 文件 | 说明 |
|---|---|
| `AlibabaPuHuiTi-3-105-Heavy.ttf` | **当前默认**。字重够，720p 竖版上清晰 |
| `AlibabaPuHuiTi-3-115-Black.ttf` | 可选更重。切 `config.SUBTITLE_FONT = "普惠体Black"` |

选 Heavy(105) 而不是 Black(115) 做默认：115 太重，笔画多的汉字
（如「镂」「潮」「腻」）在 720x1280 的字幕尺寸下容易糊成一团。
105 已经足够抢眼，又不牺牲可读性。想更重可以切，两个都支持。

## ⚠️ 这个字体不进版本库，也不由脚本自动下载

`准备素材.py` 会下 ffmpeg 和思源黑体，但**不下普惠体**。原因是实测下来
没有可靠的程序化获取渠道：

| 渠道 | 实测结果 |
|---|---|
| ⛔ `puhuiti.com` | **不是官方，是色情站，别访问**。我曾误当官网写进文档，无头浏览器超时、从未真正加载过就当事实用了 |
| 阿里 OSS 直链 | **403 Forbidden**（两个字重都试了） |
| GitHub | 搜到 18 个仓库，**全是非官方转载**（0~25 stars） |

从随机镜像下字体二进制我们不做 —— 无法验证是不是官方原版，也无法验证
随附的授权文件是否真实。这跟思源黑体那次踩的坑同类但更隐蔽：
当时从 `raw.githubusercontent` 拿到一份 1.44MB 的「OTF」，
magic 是 `OTTO` 看着像真的，**Pillow 加载才报
`horizontal metrics (hmtx) table missing`**。字体走 Pillow 渲 PNG，
加载不了就等于没有。

## 怎么装

1. 打开 https://www.alibabafonts.com
2. 找「字体下载」，取 `AlibabaPuHuiTi-3-105-Heavy.ttf`
3. 放进项目的 `fonts\` 目录
4. 跑 `python 准备素材.py --check` 确认识别到

## 缺失时会怎样

**不会崩，会自动退到思源黑体**（SIL OFL，也可商用）。
`config.FONT_FALLBACK = ["普惠体", "思源黑体", "新青年体"]` 定义了顺序，
`find_font()` 按序找第一个真实存在的文件。

所以缺普惠体只是「字幕长得不是最终样子」，不影响出片，也不影响合规
（退路思源黑体同样可商用）。**但正式交付前应该装上**，否则运营看到的
字幕样式和最终成品不一致。
